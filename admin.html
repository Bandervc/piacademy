¿Cómo obtener tu Token de GitHub? (1 minuto):
  1. Entra a GitHub → Tu foto de perfil → Settings.
  2. Baja a la izquierda a Developer Settings → Personal access tokens → Tokens (classic).
  3. Haz clic en Generate new token (classic).
  4. Marca la casilla repo (acceso completo a repositorios).
  5. Genera el token, cópialo y pégalo aquí.
